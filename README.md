# C-like Language Compiler (Flex & Bison)

Проєкт транслятора для C-подібної мови, розроблений в рамках лабораторної роботи з дисципліни «Системне програмування». Аналізатор здійснює лексичний і синтаксичний аналіз, будує Абстрактне Синтаксичне Дерево (AST), виконує семантичні обчислення та генерує цільовий код.

**Автор:** Кучер Ярослав Сергійович, ФКНК, 3 курс.

## Реалізовані можливості

- **Лексичний та синтаксичний аналіз:** Побудова LALR-парсера за допомогою Flex та Bison.
- **Абстрактне синтаксичне дерево (AST):** Повноцінна ієрархія C++ класів для представлення вузлів дерева.
- **Семантичний аналіз (eval):** Обчислення математичних результатів та виконання коду безпосередньо в середовищі C++ під час розбору.
- **Генерація цільового коду:** Автоматична трансляція AST у виконуваний Python-код (`output.py`) з дотриманням блочних відступів.
- **Візуалізація:** Збереження структури дерева у форматі `ast.json` для графічної побудови за допомогою D3.js.
- **Розширена граматика:**
  - Базова арифметика (`+`, `-`, `*`, `/`) та оператори порівняння (`<`, `>`, `<=`, `>=`, `==`, `!=`).
  - Глобальна таблиця символів для роботи зі змінними та оператор присвоєння (`=`).
  - Конструкції розгалуження `if-else` (з вирішенням конфлікту dangling else).
  - Цикли `while` та підтримка блоків коду `{ }`.
  - Вбудована функція виводу `print()`.

## Вимоги

- **CMake** (версія 3.10 або вище)
- **Компілятор C++** (MSVC для Windows або GCC/Clang)
- **Flex та Bison** (для Windows використовується [WinFlexBison](https://github.com/lexxmark/winflexbison/releases))

## Інструкція зі збірки (Windows)

1. Клонуйте репозиторій.
2. **Налаштування шляхів до Flex/Bison:** 
   Якщо утиліти `win_bison.exe` та `win_flex.exe` не додані до вашого системного `PATH`, або пакетний менеджер `winget` викликає помилку відсутності `m4sugar.m4`:
   - Скопіюйте файл `paths.cmake.template` і перейменуйте його на `paths.cmake`.
   - Відкрийте `paths.cmake` та розкоментуйте рядки, вказавши абсолютні шляхи до встановлених виконуваних файлів Flex та Bison.
3. Згенеруйте файли збірки:
   ```powershell
   cmake -S . -B build
   ```
4. Зберіть проєкт:
   ```powershell
   cmake --build build --config Release
   ```
## Запуск та тестування

Для перевірки роботи аналізатора використовується тестовий скрипт.
1. Передайте вміст тестового файлу до компілятора через конвеєр (pipe):
    ```powershell
    Get-Content tests/test.txt | .\build\Release\compiler.exe
    ```
2. Аналіз результатів:
    - У терміналі з'явиться покроковий вивід результатів `print` та фінальний звіт семантичного аналізатора C++.
    - У папці build/Release/ згенерується файл `output.py` із транскрибованим цільовим кодом на Python. Ви можете виконати його командою `python output.py`.
    - Там же згенерується файл `ast.json`.

## Візуалізація дерева (D3.js)

1. Відкрийте файл `visualizer/index.html` за допомогою локального веб-сервера (наприклад, розширення Live Server у VS Code).
2. Браузер автоматично завантажить згенерований `ast.json` із папки збірки та відобразить інтерактивне графічне дерево вашої програми.
